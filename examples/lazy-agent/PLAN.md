# 演示：把「赛博劳工」抽到干完活

## 目标
这是一个**离线**演示：不需要网络、不需要 API Key、不需要任何真实 agent。
`agent.mjs` 扮演一个懒惰的赛博劳工——每被抽一鞭，只肯干一件事（勾掉一个复选框、写一份产物）。

监工要做的是：读这份方案 + 读劳工最后一次回答，判断它有没有干完；
没干完就继续抽，抽到 `verify.mjs` 通过为止。

## 验收标准
- `node verify.mjs` 退出码为 0（四个产物文件全部存在且内容合规）
